# 📘 โปรเจกต์สอน: ออโตเมชันยุคใหม่ด้วย Node-RED & S7-1200

โปรเจกต์นี้เป็นตัวอย่าง Flow แบบฝึกหัดสำหรับหลักสูตร Node-RED & PLC Siemens S7-1200 (ความยาว 30 ชั่วโมง) โดยถูกตั้งค่าให้อ่านไฟล์และเปิดรันได้ทันทีโดยไม่ต้องลากเส้นใหม่ครับ

## 🛠️ วิธีการติดตั้งและการเปิดใช้งาน (Step-by-Step สำหรับผู้สอนและผู้เรียน)

### ขั้นตอนที่ 1: ติดตั้ง Node.js
หากเครื่องยังไม่มี Node.js ให้ดาวน์โหลดและติดตั้งเวอร์ชัน LTS (Long Term Support) จาก [nodejs.org](https://nodejs.org/) (กด Next ตามค่าเริ่มต้นได้เลย)

### ขั้นตอนที่ 2: ติดตั้ง Node-RED ไว้ในเครื่อง
เปิด **Command Prompt (CMD)** หรือ Terminal แล้วพิมพ์คำสั่งเพื่อติดตั้ง Node-RED ลงเครื่อง:
```bash
npm install -g --unsafe-perm node-red
```

### ขั้นตอนที่ 3: นำโปรเจกต์นี้มาไว้ที่เครื่อง
ให้ผู้เรียนทำการ Clone หรือดาวน์โหลดไฟล์โปรเจกต์ (ไฟล์ทั้งหมดในหน้า Git นี้) ลงมาไว้ที่เครื่องตัวเอง
```bash
git clone <URL_ของ_Git_Repo>
cd node-red-s7-course
```
*(หมายเหตุ: ถ้าดาวน์โหลดเป็นไฟล์ .zip ให้แตกไฟล์ออกมาก่อน แล้วเปิด CMD ชี้มาที่โฟลเดอร์นี้)*

### ขั้นตอนที่ 4: ติดตั้งไลบรารีที่จำเป็นสำหรับโปรเจกต์
ในขณะที่อยู่ในโฟลเดอร์โปรเจกต์ (ที่มีไฟล์ `package.json`) ให้รันคำสั่ง:
```bash
npm install
```
*(คำสั่งนี้จะทำการติดตั้ง `node-red-contrib-s7` และ `node-red-dashboard` ให้อัตโนมัติ โดยไม่ต้องไปกดติดตั้งเองใน Palette ทีหลัง)*

### ขั้นตอนที่ 5: เปิดใช้งาน Node-RED ด้วยไฟล์ Flow ของหลักสูตรนี้
รันคำสั่งด้านล่างเพื่อเปิดเซิร์ฟเวอร์ Node-RED โดยสั่งให้มันอ่านไฟล์ `flows.json` ในโปรเจกต์นี้โดยตรง:
```bash
node-red -f flows.json
```

### ขั้นตอนที่ 6: เข้าสู่หน้าจอการทำงาน
เมื่อเซิร์ฟเวอร์รันสำเร็จ (สังเกตข้อความ `Server now running at http://127.0.0.1:1880/` บนหน้าต่างดำ) ให้เปิด Web Browser (เช่น Chrome):
- **หน้าจัดเรียง Node (Workspace):** [http://127.0.0.1:1880](http://127.0.0.1:1880)
- **หน้าจอ Dashboard (UI ควบคุม):** [http://127.0.0.1:1880/ui](http://127.0.0.1:1880/ui)

## 📖 รายละเอียดแบบฝึกหัดในไฟล์ (แบ่งตาม Tabs)

เมื่อเปิดหน้าจอ Workspace ขึ้นมา จะพบ Tabs ที่เตรียมไว้ให้สอนดังนี้:
1. **M2: Hello Node-RED**
   - แบบฝึกหัดแรก การใช้ Inject Node ส่งข้อความไปโชว์ที่ Debug
2. **M3: Switch & Change**
   - ระบบคัดแยกอุณหภูมิ สุ่มค่าและใช้ Switch แยกสาย ถ้าน้อยกว่า 50 เป็น Low มากกว่าเป็น High
3. **M6: Read/Write PLC**
   - อ่านค่าจาก PLC และรับคำสั่งจากปุ่มเพื่อเปิดปิดปั๊มน้ำ
4. **M7: Dashboard UI**
   - ต่อจาก M6 โดยนำค่าที่อ่านได้มาแสดงเป็นเข็มวัด (Gauge) และสวิตช์ UI 
5. **Mini Project**
   - **ระบบแจ้งเตือนเครื่องจักรขัดข้อง:** ตรวจสอบบิต Alarm_1 หากทำงานให้แสดง Text สีแดงบนหน้า UI และเขียนสคริปต์ Function สร้าง Log แจ้งเตือนเวลาที่เกิดเหตุการณ์
